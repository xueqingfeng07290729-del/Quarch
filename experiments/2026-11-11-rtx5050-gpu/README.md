# RTX 5050：静息功耗、矩阵负载与三次重复测试

测量日期：**2026-11-11（UTC）**。使用 **QTL2312 + QTL2983-02 PCIe 主夹具与 AUX 子板**，
采集插槽三路和显卡 8-pin 外接供电，统计 `Tot` 功率与能耗。
本归档保存 **6 段完整采集、1,820 个采样点**，包含未绑定 NVIDIA 驱动时的读取验证、
安装驱动后的静息测试、首次矩阵负载以及另行执行的三次复测。

**三次复测的短时重复性良好，平均功率和能耗的轮间变异系数均为 0.0821%。**
但负载时 NVIDIA 自报功率约 130 W，Quarch 合计约 105.64–108.72 W，差异原因尚未确认。
重复性、文件完整性和分路求和一致性不能证明绝对测量准确性，也不能代替物理供电路径核对。

## 测试条件

| 项目 | 测量时的配置 |
| --- | --- |
| 显卡 | NVIDIA GeForce RTX 5050，MSI 子系统，PCI ID `10de:2d83` |
| 控制器 | QTL2312-01，目标 `USB::QTL2312-01-578`，固件 5.124 |
| 主夹具 | QTL2983-02，序列号 QTL2983-02-002，内部编号 QTL2631-02-012 |
| 接线 | 主板 PCIe → 主夹具 → 显卡；PSU 8-pin → AUX 子板 → 显卡 8-pin |
| 测量通道 | `Tot = +12V + +3.3V + +3.3Vaux + +12Vaux` |
| 软件 | QuarchPy 2.2.24、headless QIS 1.54、Python 3.12.3 |
| GPU 计算环境 | NVIDIA Open 595.99.02；CUDA Toolkit 13.2.2，nvcc 13.2.86 |
| 模拟采样 | 基础采样率 250 kHz，硬件平均 1 个样本；CSV 为相应输出窗口的平均功率 |
| 矩阵负载 | cuBLAS SGEMM，`C = A × B`，4096×4096，FP32，`CUBLAS_PEDANTIC_MATH` |
| 负载流程 | CPU 对照验证 → 连续负载预热 5 秒 → Quarch 采集 30 秒 → 停止负载并再次验证 |
| 三次复测起点 | GPU P8、利用率 0%、温度 30–32°C；后两次各自然冷却约 79 秒 |
| 风扇、频率与功率限制 | 保持默认自动策略；复测遥测功率上限 130 W，没有锁定时钟或风扇转速 |

完整接线图、夹具身份和通道定义见[显卡接线指南](../../docs/setup/qtl2312-gpu.md)。
软件版本描述的是测量当时的环境，不是对归档下载者当前机器状态的检查。

矩阵内容确定且四次负载相同，按列主序生成：

```text
A[row + col*N] = ((row + 7*col) % 17 - 8) * 0.125
B[row + col*N] = ((3*row + col) % 19 - 9) * 0.0625
N = 4096
```

[matmul_load.cu](workload/matmul_load.cu)是实际使用的源文件。每次循环批次执行 16 次 SGEMM，
随后同步；负载启动和结束时各抽查 64 个矩阵元素，与 CPU 计算比较，四次均通过，最大绝对误差为 0。
这不是对全部矩阵元素的逐项校验。`loop_matmuls` 计数包含预热和采集启动/退出开销，不能当作精确 30 秒窗口内的计算次数。

### 三次复测的稳定性

| 指标 | 三次复测统计 |
| --- | ---: |
| 平均功率的均值 | 108.651657 W |
| 平均功率的样本标准差 | 0.089197 W |
| 30 秒能耗的均值 | 3259.549697 J |
| 能耗的样本标准差 | 2.675905 J |
| 功率 / 能耗轮间变异系数（CV） | 0.082094% |
| 最高与最低轮次之差 / 三轮均值 | 0.156353% |
| GPU 利用率范围 | 99–100% |
| 起始 / 预热 5 秒后 / 结束温度 | 30/53/67°C；32/54/67°C；32/54/67°C |
| 初始 / 结束风扇百分比 | 0/44%；31/44%；31/44% |

CV 使用**三个独立轮次平均值的样本标准差 ÷ 三轮均值**，不是把 900 个采样点混为独立重复。
由于三轮都采集 30 秒，能耗与平均功率的 CV 相同。首次较高温度开始的矩阵测试单独保留，未加入本组统计。
三次复测支持本次条件下的短时重复性；温度相近不等于散热器、环境或风扇状态完全一致，不能据此断言长期热稳态。

详细数据：[逐轮对比](matmul-repeats/comparison.csv)、[统计与限制说明](matmul-repeats/summary.json)、
[三轮对齐的功率序列](matmul-repeats/power-traces.csv)。

## 功率、能耗与时间边界

- 功率来自 Quarch `Tot`，包含所测电源轨在采集窗口内的基础功耗；能耗为 `Σ(窗口平均功率 × 窗口时长)`，未扣除静息基线。
- 矩阵实验记录的是持续负载期间 **30 秒窗口的供电能耗**，不是完成一次矩阵乘法的能耗。预热不计入这 30 秒积分。
- `0, 0.1, …, 29.9 s` 的 300 个点分别代表 100 ms 窗口，总覆盖时间为 30 秒。最小/最大值是窗口平均功率，不是瞬时尖峰。
- 温度起点在启动负载前，终点在采集命令结束、负载仍运行时；温升包含预热和 QIS 启停所需时间，约覆盖 43 秒负载过程。
- NVIDIA 遥测约 1 Hz，筛选的是采集命令运行期间，包含 QIS 启停开销，与精确的 30 秒 Quarch 窗口并非严格对齐。

三次复测 PCIe 插槽合计约 **0.576–0.584 W**，外接 AUX 约 **107.973–108.145 W**；
NVIDIA 自报均值约 **130 W**，与 Quarch 的差值约 **21.28–21.48 W**。
首次矩阵负载的差值约 **24.36 W**。原始单位、连续时间戳和 `Tot` 分路求和已核对，未对差异作补偿或校正。
仍需核对实际插槽/AUX 走线、夹具配置及校准；当前数据不能证明差异由某个确定故障或温度因素造成。

## 离线复核

在仓库根目录执行，无需仪器、NVIDIA 驱动、CUDA、QuarchPy 或 QIS：

```bash
python3 tools/analysis/verify_gpu_results.py
```

校验全部文件哈希、六段时间戳与点数、总通道及各分路积分、汇总一致性、三轮统计、
温度/利用率遥测、矩阵校验记录和测量结束时保存的仪器状态。此命令不会启动 GPU 负载或连接硬件。
校验和能发现文件变化，不能证明传感器精度。

## 重新执行三次矩阵测试

先按[安装说明](../../docs/setup/installation.md)准备采集环境，并确保 NVIDIA 驱动、CUDA 和 cuBLAS 可用。
停止占用仪器的常驻服务；以下命令在仓库根目录运行，创建新的本机结果目录，不覆盖归档。
沿用原编排脚本的目录层级和固定条件：单张 NVIDIA GPU、起始 30–32°C、P8、利用率 0%、5 秒预热。
若环境无法达到这个温度范围，脚本会等待最多 10 分钟后报错，不会跳过温度条件继续测量。

```bash
(
  set -e
  archive_dir=experiments/2026-11-11-rtx5050-gpu
  mkdir -p results/gpu_matmul_repeats
  run_dir="$(mktemp -d results/gpu_matmul_repeats/reproduce-XXXXXX)"
  cp "$archive_dir/workload/matmul_load.cu" "$run_dir/"
  cp "$archive_dir/method-snapshots/repeats/run_one.py" "$run_dir/"
  /usr/local/cuda-13.2/bin/nvcc -O2 -arch=sm_120 -lcublas \
    -Xlinker -rpath -Xlinker /usr/local/cuda-13.2/targets/x86_64-linux/lib \
    "$run_dir/matmul_load.cu" -o "$run_dir/matmul_load"
  for run in r01 r02 r03; do
    mkdir "$run_dir/$run"
    .venv/bin/python -u "$run_dir/run_one.py" "$run_dir/$run"
  done
)
```

该命令生成每轮原始 CSV、在线积分和遥测；归档中的批次统计是另行离线计算的。
重新编译的二进制哈希可能随编译器/库改变，源文件哈希及本次执行二进制哈希保留在运行记录中。
复测数值会受显卡、散热、驱动、库版本和环境影响。
